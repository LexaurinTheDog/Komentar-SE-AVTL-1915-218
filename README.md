# Kommentar till avtalslagen (1915:218)

Kommentar till svensk författning: **Lag (1915:218) om avtal och andra rättshandlingar på förmögenhetsrättens område** (avtalslagen, SFS 1915:218). Kommentaren omfattar **42 enheter** (41 paragrafer, 1–41 §§, samt övergångsbestämmelserna) fördelade på 2 kommentarskapitel; vid varje paragraf återges dess ordagranna lydelse följd av en kommentar.

Lydelse enligt: konsoliderad text i Svensk författningssamling, **ändrad t.o.m. SFS 1994:1513** (Regeringskansliets rättsdatabaser / Riksdagens öppna data, publicerad 2025-10-17).

Källa: [rkrattsbaser.gov.se/sfst?bet=1915:218](https://rkrattsbaser.gov.se/sfst?bet=1915%3A218) · [data.riksdagen.se/dokument/sfs-1915-218](https://data.riksdagen.se/dokument/sfs-1915-218.json)

## Metod

Kommentaren har utarbetats **uteslutande på grundval av lokalt material** (den officiella konsoliderade texten i SFS och författningsregistret), utan användning av kommersiella juridiska databaser. Lydelsen har maskinellt hämtats ordagrant ur den officiella texten. **Rättspraxis ingår inte i denna version** – den kommer att läggas till i ett senare skede.
